# 클로드 디자인 브리프 — 일하는 외국인 공제회 (2026-10-02)

사용법: **①마스터 프롬프트를 먼저 통째로 붙여넣고**, 같은 대화에서 **②화면 블록을 하나씩** 붙여넣어 목업 생성. 한 대화에 한 화면씩이 결과가 가장 좋음. 수치·문구는 전부 검증된 값이니 **절대 바꾸거나 지어내지 말라고 명시되어 있음** — 그대로 두면 됨.

---

## ① 마스터 프롬프트 (최초 1회 붙여넣기)

```
너는 「일하는 외국인 공제회」 앱의 목업을 만든다. 정부(중소벤처기업부) 시연과 학술지 Figure에 쓰일 화면이다.

[제품] 한국의 단기순환 외국인 근로자(E-9·H-2)를 위한 개인계좌형 공제회 앱.
근로자 4% + 사업주 2~4%가 매달 개인계좌에 쌓이고, 출국하면 100% 환급된다.
사용자는 네팔·베트남·인도네시아·중국 출신 공장 근로자 — 한국어가 서툴다.
그래서 이 디자인의 제1원칙: 글을 못 읽어도 "내 돈이 쌓이고 있다"가 보여야 한다.

[디자인 컨셉 — 통장(passbook)]
일반 핀테크의 흰 카드+그림자 UI를 쓰지 않는다. 대신 모든 EPS 근로자가 아는 물건,
은행 통장의 장부(ledger) 언어로 만든다:
- 가로 괘선으로 구분되는 기입 행(row), 카드와 그림자 대신 괘선과 여백으로 위계를 만든다
- 매월 납부가 확인되면 인주(印朱) 빨강 도장 스탬프가 찍힌다 — 이 앱의 시그니처 모먼트.
  도장은 원형, 둘레에 "공제회 납입확인", 가운데 월(예: 9月), 살짝 기울고 잉크가 번진 질감
- 금액 숫자가 주인공: 아주 크게, tabular numerals, 원화 기호는 작게

[토큰]
- 종이 #F6F5F1 (배경) / 먹 #20241F (본문 잉크) / 공제녹 #0E5138 (주색: 헤더·CTA·누적액)
- 연녹 #E3EFE7 (선택·강조 배경) / 인주 #C2402A (오직 도장과 확인 표시에만 — 다른 데 쓰지 말 것)
- 괘선 #D9D6CC (1px 가로줄)
- 폰트: Pretendard (한글·숫자), 네팔어는 Noto Sans Devanagari, 베트남어 성조 깨짐 금지
- 모서리: 버튼·입력만 8px, 장부 행은 각지게. 그림자 금지, 그라데이션 금지
- 모바일 390×844 (근로자) / 데스크톱 1440 (사업주·관리자)

[규칙]
- 아래 화면 블록의 수치·이름·문구는 검증된 값이다. 절대 수정·창작 금지
- 아이콘은 선 1.5px 미니멀, 이모지 금지
- 영어 장식 문구 넣지 말 것. 화면의 언어는 블록이 지정한 언어만
```

## ② 화면 블록

### A2 — 근로자 홈 (네팔어 UI) ★ 1순위

```
화면: 근로자 홈, 모바일 390×844, UI 언어는 네팔어(하단 설명 참고), 통장 컨셉.

상단(공제녹 배경, 종이색 글자): 이름 Ramesh · 태그 E-9 · 진행 "36/58" 개월 링.
히어로(종이 배경): 라벨 "कुल रकम"(총 적립액) 작게 → 금액 ₩5,723,627 을 화면에서 가장 크게.
그 아래 장부 3행(괘선 구분, 카드 아님):
  मेरो योगदान (내 납부 4%) ....... ₩3,456,000
  रोजगारदाताको योगदान (사업주 기여) ....... ₩2,016,000
  लगानी प्रतिफल (운용수익) ....... ₩251,627
핵심: 사업주 기여 행이 '내 돈'으로 보이는 것. 행 오른쪽 금액은 tabular로 소수점 정렬.
그 아래 "이번 달" 행: 9월 납입 확인 — 인주 도장 스탬프가 찍혀 있음(시그니처).
하단 CTA 2개: [आज घर फर्किए भने] (오늘 귀국하면?) 주 버튼 / [만기까지] 보조 버튼.
```

### A4 — 환급 시뮬레이터 (네팔어 UI) ★ 2순위

```
화면: 환급 시뮬레이터, 모바일 390×844, 네팔어 UI, 통장 컨셉.

중앙에 가로 여정선(journey line): 왼쪽 끝 "입국 2023.10" — 현재 위치 마커 "오늘(36개월)"
— 오른쪽 끝 "만기 58개월". 이 선 자체가 슬라이더다. 마커를 끌면 금액이 바뀐다.
선 위 금액(가장 크게): 오늘 위치일 때 ₩5,723,627 / 만기로 끌면 ₩10,094,298.
아래 비교 장부 2행(괘선):
  공제회 (사업주 기여 포함) ....... ₩5,723,627
  현행 국민연금 반환일시금 (원금+2.2%) ....... 더 작은 금액의 짧은 막대
막대 2개의 길이 차이로 '사업주 기여만큼 크다'가 한눈에 보이게.
하단 작은 고지: "운용수익은 연 3% 보수 가정의 예시입니다" (네팔어).
주 버튼: फिर्ता दाबी (환급 신청).
```

### A5 — 출국 환급 신청 3단계 (한국어 UI로 제작)

```
화면: 출국 환급 신청 플로우, 모바일 390×844 — 3화면을 가로로 나란히 1장에.
상단 공통: 3단계 스테퍼 (신고 → 계좌 → 완료).

1단계: 출국 예정일 입력(달력), 안내 "항공권 날짜만 있으면 됩니다. 서류는 필요 없습니다."
2단계: 본국 수령 계좌 — Nabil Bank (네팔) 선택된 상태. 중간에 보안 승인 바텀시트:
  지문 아이콘 + "본인 확인" (고액 거래 승인 연출).
3단계: 완료 — 큰 인주 도장 스탬프 "접수 완료" + 문구 "출국 확인 후 3일 내 지급됩니다."
비교 각주(작게, 화면 하단): "말레이시아 EPF 출국 인출: 지점 방문·서류 4종 — 공제회: 앱 3단계·서류 0건"
```

## ③ 피드백 루프 요령
- 한 번에 한 화면. 고칠 땐 "A2에서 도장을 더 크게" 식으로 화면 번호로 지칭
- 생성 결과에 임의 수치가 보이면 즉시 "수치는 브리프 값으로 되돌려" — 수치 드리프트가 가장 흔한 사고
- 도장·괘선·숫자 크기, 이 셋이 아이덴티티. 클로드 디자인이 카드+그림자로 회귀하면 "통장 컨셉 유지" 한 줄로 교정
- 완성 목업은 논문 Figure(Ⅴ장)와 시연용 — 수출은 PNG 2x
