- 홈: 내 계좌 — 총 적립액(본인4%+사업주2~4%+운용수익), 월별 적립 타임라인

### 3. 관리자 (정책 시연용)
- 기금 대시보드: 가입자·적립총액·환급액
- 몬테카를로 시뮬레이터(기존 fund-simulator 이식): 30년 고갈확률·분위 밴드
