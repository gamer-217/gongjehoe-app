## 2. 반환일시금 이자
- NPS 공식 페이지의 검색 발췌(직접 열지 못함): https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0084M0.do (관련 페이지: https://www.nps.or.kr/pnsinfo/ntpsklg/getOHAF0079M0.do)
  - 이자는 "보험료를 낸 달의 다음 달부터 지급사유 발생일이 속한 달까지" 3년 만기 정기예금 이자율로 계산함.
  - 이자율은 매년 1월 1일 현재 전국을 영업구역으로 하는 은행의 이자율 평균임.
  - 페이지에 "2026년 3년 만기 정기예금이자율 : 2.2%"라고 적혀 있음. → 2.2%는 공식 출처의 발췌로 확인됨(PARTIAL).
- 주의: 한 블로그(wikidocs)는 2.2%를 '반납금'용 1년 만기 이자율로 설명함. 이는 NPS 발췌와 모순되므로 NPS 발췌를 우선함. 농민신문은 2025년 반납금 이율을 2.6%로 보도함(발췌만 봄).
- 이자율 단일화 경위: law.go.kr 개정이유 발췌 https://www.law.go.kr/LSW/lsRvsRsnListP.do?lsId=002833&chrClsCd=010202&lsRvsGubun=all
  - 개정 전에는 납부예외기간에 3년 만기, 자격상실기간에 1년 만기 이자율을 적용했음.
  - 개정 후에는 구분 없이 3년 만기 이자율을 적용함.
  - 2014-10-07 국무회의 의결 보도(당시 연 2.4%): https://www.hankyung.com/amp/2014100762661
- 법적 근거: 국민연금법 제77조(반환일시금). NPS 문구 "대통령령으로 정하는 이자를 더하여"가 있음 — PARTIAL.
  - 시행령 조 번호(제50조인지 다른 조인지)는 확인하지 못함 → UNVERIFIED. law.go.kr에서 직접 확인해야 함.

## 3. 출국만기보험 고시
- https://law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2000000016711
  - 제목: 「외국인근로자 출국만기보험 또는 신탁의 월적립금액 고시」
  - 고용노동부고시 제2011-33호, 2011.7.19. 전부개정, 2011.8.1. 시행
  - 근거: 외국인고용법 시행령 제21조제2항제1호
  - 검색 발췌만 봄.
- 헌재 2014헌마367(2016.3.31.)은 8.3%를 이 고시에 근거한 것으로 인용함: https://www.law.go.kr/detcInfoP.do?mode=0&detcSeq=49463
- 2011-33호를 대체하는 새 고시 번호는 검색에서 나오지 않음. 따라서 현행으로 보이지만, law.go.kr 연혁을 직접 보지 못했으므로 PARTIAL.

- 제89조 원문은 보지 못함 → PARTIAL.

## 5. KWSP Akaun Fleksibel
- 공식 Quick Guide: https://www.kwsp.gov.my/documents/d/guest/akaun-fleksibel-withdrawal_quick-guide_en
  - 발췌: "2 Choose 'Withdrawal' menu & select 'Withdraw your savings' 3 Select 'Akaun …"
  - 열 수 없었음(kwsp.gov.my 차단).
- 공식 안내 페이지: https://www.kwsp.gov.my/en/member/life-stages/akaun-fleksibel-withdrawal
- 2차 자료의 흐름(대략 6~8단계, 자료마다 다름):
  1. 로그인
  2. Withdrawal 메뉴 → Withdraw your savings
  3. Akaun Fleksibel → Withdraw Now
  4. 금액 입력
  5. 은행계좌 선택
  6. 선언 동의
  7. TAC 입력 또는 i-Akaun Secure 승인
- 공식 단계 수는 UNVERIFIED. 단계 수를 고정하지 말 것.
- 부가 사실(공식 페이지 발췌):
  - 55세 미만
  - 최소 RM50
  - RM50~RM3,000은 자동 처리
  - 승인 후 3영업일 내 지급
  - 승인 후 취소 불가
  - i-Akaun Secure 승인 필요
