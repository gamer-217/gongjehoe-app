# 연구 참여 동의서 (초안)

> 이 문서는 초안입니다. 소속 기관 연구윤리위원회(IRB)의 심의 양식과 승인 문구로 바꾸어 쓰세요. 참여자 모국어(영어·베트남어·네팔어·인도네시아어) 번역본과 통역을 함께 준비하세요.

**연구 제목:** 일하는 외국인 공제회 앱 사용성 평가
**연구 책임자:** 이성옥(코드데이원 연구소) · 연락처: ______________

## 1. 무엇을 하나요?
휴대폰으로 연습용 앱을 써 보고 다섯 가지 일을 해 봅니다. 예를 들면 "내 돈이 얼마인지 말하기" 같은 일입니다. 약 30분이 걸립니다.

## 2. 무엇을 기록하나요?
- 앱 안에서 누른 순서와 걸린 시간(이름·전화번호·외국인등록번호는 기록하지 않습니다)
- 진행자의 관찰 메모
- 동의한 경우에만: 화면과 목소리 녹화

## 3. 실제 돈과 관계가 있나요?
아닙니다. 앱의 사람과 금액은 모두 연습용입니다. 실제 계좌, 보험, 비자에는 아무 영향이 없습니다.

## 4. 그만두고 싶으면?
언제든지 그만둘 수 있습니다. 그만두어도 불이익이 없습니다. 이미 모은 기록은 원하면 지웁니다.

## 5. 기록은 어떻게 다루나요?
- 기록에는 이름 대신 번호(P01, P02…)만 씁니다.
- 연구가 끝나고 ___년 뒤 파기합니다.
- 연구 결과는 논문과 보고서에 묶음 통계로만 실립니다.
