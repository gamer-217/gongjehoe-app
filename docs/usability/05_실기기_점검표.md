# 실제 휴대폰 점검표 (5분)

주소: https://gamer-217.github.io/gongjehoe-app/
가능하면 중저가 안드로이드(갤럭시 A 시리즈 등)와 아이폰을 하나씩 씁니다. 결과는 칸에 ○/✕로 적고, ✕이면 화면 캡처를 남겨 주세요.

| # | 확인할 것 | 방법 | 안드로이드 | 아이폰 |
|---|---|---|---|---|
| 1 | 첫 화면이 2초 안에 뜨나 | 와이파이 끄고 LTE로, 주소창에 `.../#/w/W001` 입력 후 초 세기 | | |
| 2 | 하단 탭이 바닥에 붙어 있나 | 홈에서 아래로 끝까지 스크롤 | | |
| 3 | 네팔어 글자가 깨지지 않나 | 지구본 → नेपाली → 홈·보장 지도 보기 | | |
| 4 | 베트남어 성조 표시가 정상인가 | 지구본 → Tiếng Việt | | |
| 5 | 가로로 밀리는 화면이 없나 | 각 탭을 열고 좌우로 밀어 보기 | | |
| 6 | 글자 크기 200%에서도 읽히나 | 휴대폰 설정에서 글자 크게 → 홈·신청 화면 | | |
| 7 | 버튼이 손가락으로 누르기 쉬운가 | 받기 → 환급 신청 → 달력 날짜 누르기 | | |
| 8 | 홈 화면에 추가가 되나 | 브라우저 메뉴 → 홈 화면에 추가 → 아이콘으로 실행 | | |
| 9 | 오프라인에서 열리나 | 8번 뒤 비행기 모드 → 아이콘 실행 | | |
| 10 | 듣기 버튼 | 지원 언어에서만 보이는 게 정상(없어도 됨) | | |

1번이 2초를 넘으면 기종과 걸린 시간을 알려 주세요. 다음 개선 때 반영합니다.
