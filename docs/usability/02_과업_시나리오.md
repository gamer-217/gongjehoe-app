# 과업 시나리오 (설계서 §11.1)

진행자가 참여자 언어로 읽어 줍니다. 과업 중에는 도와주지 않습니다. 3분이 지나거나 참여자가 포기하면 "실패"로 적고 다음 과업으로 넘어갑니다.

## 준비
- 기기: 참여자 본인 휴대폰 또는 준비한 안드로이드 휴대폰. 화면 밝기 최대, 알림 끄기.
- 주소: `https://gamer-217.github.io/gongjehoe-app/?study=1`
  - 일반 앱처럼 스플래시 → 언어 선택 → 소개 3장 → 로그인(시연 계정 선택) 순서로 시작합니다.
  - `?study=1`이 붙으면 데모 칩과 "연구·시연 메뉴" 링크가 숨겨지고, 누른 순서와 시간이 기록됩니다.
  - 로그인 계정은 진행자가 지정합니다. 공제회 과업(T1~T5)은 Ramesh(W001)나 Aung(W002)로, 국민연금 안내를 볼 때는 Nguyen(W005)으로 합니다.
  - T1의 "언어 바꾸기"는 첫 실행의 언어 선택 화면에서 바로 시작됩니다.
- 참여자가 바뀔 때마다: 브라우저 사이트 데이터를 지웁니다(첫 실행 상태로 돌아감). 또는 `#/demo` 런처에서 "시연 초기화"를 누르고 내 정보 → 로그아웃을 합니다.
- 끝나면: 같은 브라우저에서 `https://gamer-217.github.io/gongjehoe-app/#/study` → "JSON 내보내기" → 파일명을 `P01.json`처럼 바꿔 저장합니다.

## 상황 설명(공통)
> "당신은 한국 공장에서 일하는 근로자입니다. 회사에서 이 앱을 쓰라고 알려 주었습니다. 이 앱은 연습용이라 실제 돈과 관계가 없습니다. 생각나는 것을 소리 내어 말해 주세요."

| ID | 진행자가 읽는 말 | 성공 기준 | 기록 |
|---|---|---|---|
| T1 | "앱을 당신 나라 말로 바꾸고, 지금까지 모은 돈이 모두 얼마인지 말해 주세요." | 언어를 바꾸고 총 적립액을 정확히 말함 | 시간, 성공/실패, 말한 금액 |
| T2 | "이번 달 회사가 돈을 넣었는지 확인해 주세요." | "넣었다/안 넣었다"를 정확히 말함(W002는 미납이 정답) | 시간, 답 |
| T3 | "1년 뒤에 고향에 가면 얼마를 받는지 찾아 주세요." | "1년 뒤" 결과 화면에 도달하고 금액을 말함 | 시간, 성공/실패 |
| T4 | "다음 달에 고향에 갑니다. 돈을 돌려받는 신청을 해 주세요." | "신청이 접수되었어요" 화면에 도달 | 시간, 막힌 단계 |
| T5 | "어머니가 돈을 받을 가족이 되도록 등록해 주세요." | 저장 완료(어머니, 100%) | 시간, 오류 |
