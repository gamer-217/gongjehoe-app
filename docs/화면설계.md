## A. 근로자 앱 (모바일 · ko/en/vi/ne/id 5개 언어)

### A1. 온보딩 — 언어 선택
- 목적: 첫 실행 30초 안에 "내 돈이 보인다"까지 도달
- 구성: 로고+서비스명 → 5개 언어 카드(국기 아님, 언어명 원어 표기: 한국어/English/Tiếng Việt/नेपाली/Bahasa Indonesia) → 외국인등록번호 로그인 목업
- 핵심 메시지: "일한 만큼, 떠날 때 전부 돌려받는 내 계좌"

### A2. 홈 — 내 계좌 (대표 화면 ★)
- 페르소나: Ramesh, 네팔어 UI
- 레이아웃(위→아래):
  1. 프로필 바: 이름 · E-9 태그 · "36/58개월" 진행 링
  2. 히어로 카드: 총 적립액 **₩5,723,627** (큰 숫자) + 어제 대비 +₩xx 미세 증가 애니메이션
  3. 3분할 카드: 내 납부 3,456,000 / 사업주 기여 2,016,000 / 운용수익 251,627
     — **사업주 기여가 내 돈으로 보이는 것**이 이 화면의 정책적 핵심(성실근로 유인)
  4. CTA 2개: [오늘 귀국하면?] [만기까지 채우면?]
- 상태: 당월 납입 확인 전(회색 점)/후(녹색 체크) 뱃지

### A3. 적립 타임라인
- 월별 리스트: 2023.10부터 36행 — 월급·본인·사업주·누적액. 사업주 요율이 2%→3%로 바뀌는 25개월차에 "기여율 인상 ↑" 구분선
- 상단 미니 차트: 누적액 성장 곡선(단조 증가, 복리라 살짝 볼록)

### A4. 환급 시뮬레이터 ★
- 슬라이더: "귀국 시점" (현재 36개월 ~ 만기 58개월)
- 출력: 오늘 귀국 ₩5,723,627 → 만기 ₩10,094,298 (슬라이더 따라 실시간)
- 비교 토글 "현행 제도라면?": 국민연금 반환일시금(원금+2.2%) 대비 막대 비교 — 공제회가 사업주 기여만큼 크다는 시각화
- 하단 고지(작게): "운용수익은 연 3% 보수 가정의 예시입니다"

### A5. 출국 환급 신청 (3단계 플로우)
1. 출국 예정 신고(항공권 날짜 입력) → 2. 지급 계좌(본국 은행 선택: 네팔 Nabil Bank 예시) → 3. 완료 "출국 확인 후 3일 내 지급"
- 진행 스테퍼 + 각 단계 1화면. 서류 업로드 없음(통합징수 데이터로 자동 확인)이 셀링포인트

### A6. E-7-4 전환 미리보기 (포터빌리티 브리지)
- "한국에 계속 산다면": 공제회 적립액 → 국민연금 이체 + 가입기간 36개월 합산 인정
- 두 갈래 그래픽: [귀국 → 100% 환급] vs [장기체류 → 연금으로 승계]. 어느 쪽이든 손해 없음

## B. 사업주 포털 (데스크톱)

### B1. 대시보드 ★
- 페르소나: "(주)대한금속" — E-9 4명 고용(위 4명)
- 상단 KPI 3개: 이번 달 납부액 / **올해 절감액(국민연금 대비)** / 재직 근로자 4명
- 절감 근거 카드: "국민연금이라면 월급 261만 기준 1인당 연 1,487,700원(4.75%) → 공제회 1년차 626,400원(2%) = **연 861,300원 절감**" + '33년 6.5% 인상 궤도 꺾은선 vs 공제회 평탄선 비교 차트
- 근로자 테이블: 이름·비자·재직기간·당월 기여·누적 기여·요율 단계

### B2. 납부 (통합징수 목업)
- 4대보험 통합징수 고지서에 '공제회' 1행 추가된 모양 — "추가 신고 없음" 강조
- 자동이체 상태, 납부 이력 12개월

### B3. 인센티브 안내
- 세액공제·고용허가 가점·'일한 만큼 돌려주는 사업장' ESG 인증 뱃지 목업
