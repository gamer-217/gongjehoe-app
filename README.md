# 일하는 외국인 공제회 — 프로토타입 (gongjehoe-app)

단기순환 외국인력(E-9·H-2)용 개인계좌형 공제회의 시연 프로토타입.
근거: 이성옥·김태희(2025), 다문화콘텐츠연구 54집, 89-119 / 정책제안서(2026.10).

## 실행
빌드 불필요. `index.html` 더블클릭 (또는 `python3 -m http.server`).
의도적으로 무의존성(바닐라 JS) — Dropbox 동기화·인수인계 최소 마찰.

## 구조
- `index.html` — 단일 진입점, 3역할(근로자/사업주/관리자) 전환
- `js/data.js` — 목데이터(요율·가상 근로자·기금), 제도 파라미터 단일 소스
- `js/i18n.js` — 5개 언어(ko/en/vi/ne/id)
- `js/app.js` — 화면 렌더링·환급 시뮬레이터
- `docs/기능정의.md` — 화면 플로우·로드맵(D1~D7)

## 로드맵
D1 스캐폴드·기능정의(완) → D2~3 근로자 앱 → D4 사업주 포털 → D5 관리자 대시보드(몬테카를로) → D6 통합·시나리오 → D7 데모 패키징
